# 🧠 How I Study a Problem

For important problems, the goal is to follow this process:

```text
1. Understand the problem
        ↓
2. Identify the important constraints
        ↓
3. Think about the brute-force solution
        ↓
4. Find the bottleneck
        ↓
5. Look for a useful observation
        ↓
6. Identify the DSA pattern
        ↓
7. Derive the optimized solution
        ↓
8. Implement it
        ↓
9. Test edge cases
        ↓
10. Analyze Time & Space Complexity
```

This approach is especially useful when solving an **unfamiliar coding problem during a placement assessment**.

# 📖 README Philosophy

The problem READMEs in this repository are intended to answer four important questions:

> **1. How do I recognize this type of problem?**

> **2. How do I decide what approach to use?**

> **3. How do I derive the solution from the problem statement?**

> **4. How can I reproduce the solution independently during a coding round?**

The focus is therefore on **thinking and pattern recognition**, not memorizing code.
